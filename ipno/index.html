Suggestions indirectes

Principe : en hypnose ericksonienne on propose une expérience sans l’imposer.

Techniques principales

  • Permissive : « vous pouvez… »
  • Présupposition : « pendant que… »
  • Double choix : « maintenant ou dans quelques instants ? »
  • Métaphore : utiliser une image
  • Ratification : valider ce qui apparaît déjà

Observer la réaction du patient

  • sceptique → permissive
  • contrôle → double choix
  • analytique → métaphore
  • coopératif → présupposition
  • début de transe → ratification

Logique :

Observer → Adapter → Amplifier
