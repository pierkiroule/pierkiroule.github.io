Le message d’Eko

Salut explorateurs du labyrinthe,

Dans le mythe grec, Thésée entre dans le labyrinthe. Un endroit fascinant, mais où l’on peut vite se perdre.

Le Minotaure n’est pas seulement un monstre. Aujourd’hui il ressemble parfois à :

  • la fatigue des écrans
  • les images qui blessent
  • les messages qui mettent la pression
  • le cyberharcèlement

Thésée ne gagne pas parce qu’il est le plus fort.

Il s’en sort parce qu’Ariane lui donne un fil.

Un fil pour explorer… sans se perdre.

Je vous propose un défi :
prenez 10 minutes ensemble pour créer votre propre Fil d’@riane.

— Eko
